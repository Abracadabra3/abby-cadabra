I build and compete with combat robots! If you haven't heard of combat robots before, it's basically custom RC cars with custom saws fighting each other to the death.
Here is a list of the combat robots I have built

Ace of Sharks v3


Ace of Sharks v3 is a grappler combat robot that uses the same mechanism as the BattleBot Claw Viper. The goal is to grab another combat robot and lift it into the air and flip it over.
The current iteration of Ace of Sharks is fully open source on GitHub here!

Ace of Sharks v1


Ace of Sharks v1-2 is a lifter combat robot with a specially designed lifter arm shape to try to lift opponents into the air.
Ace of Sharks v1 got second place at it's first tournament.

HHH: Hazardously Hangry Hippo


HHH is a RoboClash Kit combat robot which I started competing with. I learned to iterate and make it better after every event by making the parts that broke stronger. This prepared me to design Ace of Sharks!
